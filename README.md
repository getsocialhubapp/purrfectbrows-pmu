# Purrfect Brows PMU

Business website for Diana — AAM board-certified PMU artist in New Jersey (@purrfectbrows.pmu).

Built to attract clients: services, portfolio, process, about, FAQ, and Instagram-DM booking.

## Hosting

GitHub Pages from `main`. `.nojekyll` disables Jekyll processing.

## Portfolio photos

`portfolio.json` maps each Instagram post to a photo file in `photos/`. To add a photo: drop the file in `photos/` and set the post's `"photo"` field to the filename.
